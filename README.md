## Built With

- HTML
- Tailwind css
- javaScript
- Noroff API

## Features

- Responsive design
- User can register user
- User can log in
- User can see posts feed
- Search posts
- Filter posts
- User can create post
- User can delete post ("are you sure" message)
- User can edit post
- User can view post content by id (single post viewer)
- User can log out
